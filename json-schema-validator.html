JSON Schema validator

Check JSON data against a carefully scoped 2020-12 subset, locally.

Supported: boolean schemas, type, enum, const, minimum/maximum/exclusive bounds, multipleOf, min/maxLength, min/maxItems, uniqueItems, items, prefixItems, min/maxProperties, required, properties, additionalProperties, allOf, anyOf, oneOf, not. Unsupported keywords are reported, never ignored. No $ref, format, regex or remote fetches.

    Is this a complete JSON Schema validator?

    No. It implements only the listed 2020-12 validation keywords. It rejects unknown keywords, rather than quietly claiming a document is valid. It has no $ref resolution, regular expressions, format checking or remote schema loading. `uniqueItems` uses semantic JSON equality, including objects regardless of property order. For production contracts, use a full standards-tested validator.

    Where is my data sent?

    Nowhere. Both schema and JSON remain on this device.
