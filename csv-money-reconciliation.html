How this comparison works

Exactly one record per trimmed ID in each export. Amounts are signed, exact hundredths, from -1 billion to +1 billion per record. Header-only files are valid empty exports. Non-key columns are ignored after CSV syntax and row width checks. Blank physical lines are ignored; records with empty IDs are rejected. A leading byte-order mark is ignored.

Quoted fields can contain commas, line breaks and doubled quotes. Delimiters are commas; LF, CRLF and CR line endings are accepted. Spaces after a closing quote are rejected rather than guessed. This is not a general-purpose spreadsheet import.

Limits and privacy

Not for currencies requiring more than two decimal places. No rounding, exchange rates, tax interpretation, fuzzy matching or duplicate summing. Equal totals do not imply equal records. Check IDs and the accounting basis before using this as evidence.

Both exports stay in this browser session. No storage, uploads, trackers or external requests. Download contains raw_id_json, a lossless JSON string of each exact matched ID, and display_id, a spreadsheet-safe ID prefixed with an apostrophe when needed. Use raw_id_json for round trips; JSON-decode it to recover the original ID. Currency and basis are also JSON strings. Display IDs alone can collide; they are not matching keys. Generated numeric amount cells are plain decimal numbers.

CSV format background: RFC 4180. The accepted line endings and strict limits above define this tool's own behavior.
