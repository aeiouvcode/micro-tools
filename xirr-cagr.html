How is XIRR different?

XIRR uses each actual date and a 365-day year. CAGR uses just starting value, ending value and elapsed years. After combining entries on the same date, this tool requires exactly one chronological sign change. That gives a unique finite root if one exists. Repeated sign changes are refused because a simple sign-change scan can miss close or touching roots. The supported search range is above -99.9999% and up to 10,000,000,000%. A rate outside it is not reported. This is a numerical estimate, not a guarantee of future performance. Microsoft's XIRR guide explains irregular flows.
