Why most Base64 tools break on non-English text

The browser's legacy btoa() only accepts byte-sized characters, so pasting Hindi or emoji into most online tools throws an error or silently corrupts. This tool encodes through UTF-8 first, so any text survives: paste it, encode, decode, get it back exactly.

What URL-safe means

Standard Base64 uses + and /, which need escaping inside URLs and filenames. The URL-safe variant swaps them for - and _ (RFC 4648 section 5) - use it for tokens and query parameters. All processing happens on your device.
