JSON Pointer resolver

Find a value inside JSON using an RFC 6901 pointer.

Escape / in a key as ~1 and ~ as ~0. Array indices start at 0; leading zeroes are not allowed.

Resolved value-
Is this JSONPath?
No. JSON Pointer (RFC 6901) is an exact path, not a query language: /user/roles/0 selects one value. It distinguishes a missing value from JSON null. It also resolves an empty-key property using / and leaves the empty pointer as the whole document.
Is my JSON uploaded?
No. Parsing and lookup happen on your device.
